Frequently asked questions

What is MDViewer?

MDViewer is a native macOS app for viewing and editing Markdown files, with a workspace file browser, live preview, syntax highlighting, and export options.

Does MDViewer require an internet connection?

No. MDViewer works entirely offline. All files you open stay on your Mac, and the app does not send your documents anywhere.

What file types does MDViewer support?

MDViewer opens Markdown files (.md, .markdown, .mdown, .mkd) and plain text files, and can export documents to other formats from within the app.

How do I open a folder as a workspace?

Use File → Open Workspace (or drag a folder onto the app icon) to browse and edit every Markdown file in that folder from the sidebar.

I found a bug. How do I report it?

Email alice.turcanu91@gmail.com with a description of the issue, your macOS version, and the MDViewer version (found under MDViewer → About MDViewer). Screenshots or a sample file that reproduces the problem are very helpful.

Can I suggest a new feature?

Yes — feature requests are welcome at the same email address above.

Before you contact us

Make sure you're running the latest version of MDViewer from the Mac App Store, and that your macOS is up to date. Many display or performance issues are resolved by updating both.
