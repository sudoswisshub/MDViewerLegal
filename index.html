MDViewer

A native Markdown reader and editor for macOS.

MDViewer opens any Markdown file and shows it the way it was meant to be read: real headings, clean typography, syntax-highlighted code, proper tables, and images in place. When something needs changing, switch to the editor, type, and save straight back to the file on disk.

It is a native macOS app — not a browser in a wrapper. No account, no subscription, no internet connection, and nothing about your documents ever leaves your Mac.

Read

Headings, lists, tables, block quotes, links, images, and code highlighted in 18 languages. Adjustable text size and content width, light or dark.

Browse a folder

Open a whole folder and move between its Markdown files from the sidebar. Filter by name, or search the text inside every document in it.

Edit in place

A real editor with highlighted source, live preview alongside it, and formatting shortcuts. Saving writes back to the original file.

Export and share

Export as PDF or HTML, copy as rich text, copy the HTML source, or print exactly what you see on screen.

Privacy

MDViewer collects nothing. There are no accounts, no analytics, no advertising, and no network features at all — even images hosted on the web are never fetched; they appear as a placeholder you can choose to open in your browser. The app is sandboxed and only ever touches the files and folders you open yourself. Full details are in the privacy policy.

Requirements

  • macOS 15 or later
  • Apple silicon or Intel
  • Opens .md, .markdown, .mdown, .mkd and plain text files
